# 来源证据与存量例外

整改日期：2026-09-05。基线 main@bd0abb3。

`legacy-sources-20260905.json` 是固定 200 条存量来源的工程兼容快照，不是授权清单。slug、iframe URL、来源页面必须全部相符；更换域名、路径或来源页面不能沿用旧例外。manual-review 与 blocked 优先拒绝。禁止追加新条目来绕过审批，测试校验整个快照哈希。

新导入或替换目录来源：先在 `docs/licenses/` 保存可复核许可与素材证据，再向 `APPROVED_CATALOGUE_SOURCES` 添加作者、许可、版本、证据路径、审核日期、实际可玩检查日期、商用及嵌入许可。仅改 `embedPermissionStatus` 字段不构成证据。新增 active 与 pending→active 的写路径均要求独立审核；非活跃待审记录可保存但不得播放/索引。
