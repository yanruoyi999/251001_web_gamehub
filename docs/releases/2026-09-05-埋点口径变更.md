# 游玩埋点口径 v2

该分支引入 `schema_version=2`，合并与部署时间尚未确认；不能把此文档日期视为生产切换日期。

| 事件 | 唯一能证明的事实 |
| --- | --- |
| game_start_attempt | 用户发出了开始请求，不证明加载或游玩成功。 |
| game_iframe_load | 浏览器观察到 iframe load；跨域错误页也可能触发，不证明可玩。 |
| game_load_success | 自托管运行时通过来源窗口、opaque origin、slug、随机会话核验并发送 ready。 |
| game_play_start | 自托管运行时第一次接收到有效的可信键盘操作。每个 iframe 会话一次。第三方 iframe 不伪造这个事件。 |
| game_play_10s / game_play_30s | 首次有效操作后，文档可见时间达到阈值。不是逐帧活跃操作或通关证明。 |

新旧 `game_play_start` 不能直接同比，旧版代表点击按钮。历史数据不能倒推出新口径。开始分析时应记录实际部署时间并分段，不回填、不补造事件。

每日纸牌完成事件按局去重；同局撤销后再完成不重复发送。连续天数以去重的真实游玩日记录为准。离线、预览与本地测试保持采集隔离；自动化的断言使用本地内存记录器，不写入真实统计。
