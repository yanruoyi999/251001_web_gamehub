# Original Sorting Games Hub — Design

## Goal

Build one high-quality, indexable `/en/games/sorting-games` core asset that targets the broad `sorting games` intent with three Luma-original browser games. The first release must create useful playable value without copying any third-party game, name, artwork, audio, level layout, code, iframe, or asset.

## Growth Strategy Fit

- One search intent → one core page. Do not create separate `ball sort`, `water sort`, `color sort`, or `sort game` pages in this release.
- Validate impressions, ranking, clicks, starts, completion, and repeat play before second-layer expansion.
- Keep homepage curation unchanged. Discovery must come from contextual game/guides pages, not sitewide links.
- Treat the page as a reusable SEO asset: strong first-party gameplay, clear controls, descriptive content, schema, sitemap, and measured interaction.

## Copyright / IP Boundary

Allowed:
- Luma-written TypeScript/React logic.
- CSS/DOM geometric visuals created in this repository.
- Generic sorting mechanics and generic descriptive terms.
- Procedurally generated numeric/color/shape states.

Blocked:
- Third-party game source code, screenshots, sprites, music, SFX, logos, character art, level layouts, brand names, or copied instructions.
- External game iframe/runtime URLs.
- Claims that a third-party game is licensed unless repository evidence exists.
- Exact third-party game titles in product naming or metadata merely to capture traffic.

## Core Route

- English: `/en/games/sorting-games`
- Chinese localized route is generated by the existing locale architecture.
- H1: `Sorting Games Online`
- Primary intent cluster: `sorting games`, `sort games`, `sorting games online`, `color sorting game`, `number sorting game`.
- Do not optimize the page as a branded clone of any existing ball/water-sort product.

## Original Games

### 1. Color Stack Sort

A compact stack puzzle using only CSS color tiles. Players move the top tile between stacks. A move is valid when the destination is empty or its top tile matches the moving color. The goal is to group every stack into a single color.

- Deterministic challenge seed.
- No copied commercial level layouts.
- First release uses Luma-generated levels from a small procedural generator.

### 2. Number Order Sprint

A quick sorting challenge. A shuffled set of integers is shown as tiles; players tap them in ascending order. Wrong taps add a mistake count but do not reveal third-party data or content.

- New deterministic sequence per challenge seed.
- Completion time stays browser-local.

### 3. Shape Shelf Sort

Players sort Luma-drawn CSS geometric cards into `3 sides`, `4 sides`, and `round / other` shelves. Shapes are constructed from CSS/text labels, not external images.

- Designed as a fast educational/recognition sorting game.
- No external asset dependency.

## Player Architecture

Create one client component that owns local state for all three games. Only one game is active at a time. No database, API, localStorage, account, realtime room, or network fetch is required for game state.

A six-character challenge code controls deterministic shuffling/generation. Sharing writes only the challenge code to the URL (`?challenge=ABC234`). It must never serialize moves, answers, time, score, or player identity.

## Analytics and Privacy

Custom events may include:
- `sorting_collection_view`
- `sorting_game_start`
- `sorting_game_complete`
- `sorting_game_switch`
- `sorting_challenge_share`

Allowed dimensions: `game_slug`, `challenge_code`, `round_count`, `mistake_count`, `completion_ms` bucket or integer.

Do not send tile values, move history, exact answer sequence, names, or free text.

Unlike Couples, these games are not intimate/sensitive content, so normal site analytics may remain enabled. Playwright telemetry isolation must still block test traffic.

## SEO / Structured Data

- Canonical and hreflang via existing locale helpers.
- `CollectionPage` + `ItemList` describing the three Luma-original games.
- `VideoGame` JSON-LD entries for each original game, explicitly identifying Luma Game Hub as creator/publisher.
- FAQ content for what sorting games are, device support, and whether downloads/accounts are required.
- Add to sitemap.

## Internal Links

Create only contextual discovery links:
- `/games` → Sorting Games.
- one existing puzzle/no-download guide → Sorting Games.
- Sorting Games → `/games`, `/games/online-games-for-couples`, and `/games/2-player-unblocked` where relevant.

Do not add a homepage recommendation in this release.

## Quality Gates

- Static page-quality score >= 80.
- Runtime-quality samples the English Sorting Games page.
- Playwright covers desktop Chromium/Firefox/WebKit and existing mobile projects through the shared test matrix.
- E2E covers loading, switching games, one complete Number Order Sprint, challenge-code reload determinism, and no horizontal overflow.
- Lint, type-check, internal-link audit, unit tests, production dependency audit, production build, E2E, and runtime-quality must all pass on the exact final head.

## Expansion Rule

No second-layer sorting URL should be created until the core page has enough real GSC evidence to justify it. Expansion candidates are based on actual query growth and ranking, not keyword-tool volume alone.
